# Coderhouse - SQL

Repositorio con las entregas de trabajos prácticos correspondientes al curso de **SQL de Coderhouse**.

## 📋 Descripción

Este repositorio centraliza las distintas entregas realizadas a lo largo del curso, incluyendo scripts SQL, diagramas de base de datos y documentación asociada a cada práctica.

## 📁 Estructura del repositorio

Cada carpeta corresponde a una entrega del curso, numerada según el orden en que fue solicitada:

```
Coderhouse-SQL/
├── 02 - Tablas principales con restricciones y datos iniciales/
│   ├── script.sql
│   └── ...
└── README.md
```

> A medida que se sumen nuevas entregas, se agregará una carpeta numerada (03, 04, ...) con su contenido correspondiente.

## 📦 Entregas

| # | Entrega | Descripción |
|---|---------|-------------|
| 02 | [Tablas principales con restricciones y datos iniciales](./02%20-%20Tablas%20principales%20con%20restricciones%20y%20datos%20iniciales) | Creación de las tablas principales del modelo de datos, con sus restricciones (PK, FK, NOT NULL, UNIQUE, etc.) y carga de datos iniciales. |

## 🛠️ Tecnologías utilizadas

- SQL (PostgreSQL)
- Git y GitHub para el control de versiones

## 🚀 Cómo ejecutar los scripts

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/davidcarusso/Coderhouse-SQL.git
   ```
2. Ingresar a la carpeta de la entrega que se desea revisar.
3. Ejecutar el/los script/s `.sql` en el motor de base de datos correspondiente.
